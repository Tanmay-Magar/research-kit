# tanmay-tools

Personal Claude Code marketplace. Plugin `research-kit` adds two subagents:
`researcher` (Sonnet, web search, returns a claims ledger) and `validator`
(Haiku, re-checks only dates, numbers, money, health and legal claims against
a primary source: confirmed / wrong / unverifiable).

Install on any machine:

    /plugin marketplace add <magartanmay@gmail.com>/<research-kit>
    /plugin install research-kit@tanmay-tools
